# Language & Presentation Policy

- **Technical Implementation Language**: English is permitted and preferred for internal architecture, TypeScript identifiers, database schemas, table and column names, enums, comments, test names, route segments, and git commits.
- **User-Facing Application Language**: **Turkish ONLY**. Every user-facing UI string rendered by the application (customer booking flows, dashboard agendas, forms, buttons, titles, empty states, error boundaries, 404 pages, badges, role/status labels, and validation/server action error messages displayed to users) must be in Turkish.
